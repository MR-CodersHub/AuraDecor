# AuraDecor — Premium Handicraft & Home Decor Store

A luxury, visually rich, and fully responsive e-commerce web platform for **AuraDecor**, celebrating authentic Indian craftsmanship, artisan heritage, and contemporary slow-living aesthetics.

Built entirely using **pure HTML5, CSS3, and Vanilla JavaScript (ES6)** with zero third-party framework dependencies.

## Brand Identity & Visual Assets

- **Official Tagline**: *Timeless Craft · Soulful Living*
- **Favicon**:
  - `assets/images/favicon.svg`: Handcrafted 8-point artisan star with terracotta gradient base (`#B9684E`), golden filigree border, and warm sand core (`#F8F3E9`).
  - `favicon.svg`: Root-level vector favicon for browser auto-detection.
- **Logo**:
  - `assets/images/logo.svg`: Master vector logo featuring the handcrafted artisan emblem, Playfair Display serif wordmark, and clean sans-serif tagline.
  - Linked and integrated with inline vector optimization across all 12 pages in both navigation and footer sections.

## Shared Assets & Architectural Highlights

- [style.css](file:///c:/Users/LOKII_1526/Desktop/AuraDecor/assets/css/style.css): Full typography scale, CSS custom properties, responsive grids, buttons, badges, modals, and design tokens.
- [responsive.css](file:///c:/Users/LOKII_1526/Desktop/AuraDecor/assets/css/responsive.css): Granular breakpoint overrides for 1200px, 992px, 768px, and 480px viewports.
- [main.js](file:///c:/Users/LOKII_1526/Desktop/AuraDecor/assets/js/main.js):
  - **Dark / Light Theme Toggle**: Persisted to `localStorage` (`data-theme="dark"`).
  - **RTL / LTR Layout Toggle**: Persisted to `localStorage` (`dir="rtl"`).
  - **Interactive Sliding Cart Drawer**: Live add-to-cart, remove, quantity adjustments, subtotal recalculation, and empty-state messaging.
  - **Wishlist System**: Persisted via `localStorage` with live header badge counters.
  - **Scroll Reveal Animations**: Dynamic Intersection Observer triggers.
  - **Toast Notifications**: Reusable feedback alerts.
- [products-data.js](file:///c:/Users/LOKII_1526/Desktop/AuraDecor/assets/js/products-data.js): Comprehensive mock dataset containing 24 handcrafted products across 10 craft categories, artisan biographies, and journal articles.
